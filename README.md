# Technical enablement demos

Public-safe workflow explanations and interactive reconstructions by Hernan Acosta.

- [Learning Studio visual flow](learning-studio.html?scoutTheme=light): one product record across Create, Creations, and Workroom; tracked draft jobs; connected outputs; version-specific review; separate publication.
- [FC IT ticket intake](ticket-flow.html?scoutTheme=dark): nine issue categories, short structured forms, and fictional submission confirmations.
- [Learning Studio flow image](learning-studio-flow.png) and [editable diagram source](learning-studio-flow.excalidraw).

## What this repository is

This site is static HTML, CSS, and JavaScript. It is not the original internal applications, a live Power Apps deployment, or a connected ticketing service. All example records, jobs, files, approvals, and confirmations are fictional.

The existing Learning Studio web demo described in the visual uses React/TypeScript, Node.js, and SQLite with real local saved interactions and simulated native integrations. That application and its database are not included here.

The Power Apps, Power Automate, controlled AI, SharePoint, and Dataverse architecture is the intended native design. Power Apps/Dataverse development is paused. PA Studio invocation, input/output contracts, Word-template bindings, identity, permissions, and licensing still require verification.

## Use

Open the GitHub Pages site, or download an HTML demo and open it directly in a modern browser. The demo pages contain their styles and scripts; the ticket page also embeds its equipment photographs. No installation, company account, or live backend is needed.

## Privacy and attribution

No company credentials, private source documents, actual tickets, or backend connections are included. The applications do not submit entered details to a server and do not include app analytics. GitHub Pages hosting is subject to GitHub's own service and privacy policies.

Equipment photos are public Wikimedia Commons illustrations, not Amazon-internal images or logos. Source, author, license links, and display modifications are listed in the ticket page's **Equipment photo credits** dialog. Each photo retains its stated license.

These are independent project explanations, not official Microsoft or Amazon products or services.
